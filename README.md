# П'ять рівнів

Лабораторна робота № 8 з дисципліни «Обробка мови методами штучного інтелекту»
(LLM-проєкт, базовий рівень). Виконав Сидор Дмитро, група ШІ-42.

Сервіс пояснює одну тему на п'яти рівнях складності: для дитини, школяра, студента,
фахівця та експерта. Рівень перемикається повзунком.

- Сервіс: https://huggingface.co/spaces/sydordmytro/five-levels
- Код: https://github.com/dmytrosydor/five-levels

## Як працює

1. Користувач вводить тему, свій ключ і обирає модель.
2. Сторінка робить один запит до LLM. У промпті описано п'ять рівнів і сказано повернути
   тільки JSON з ключами `child`, `school`, `student`, `pro`, `expert`.
3. З відповіді береться лише те, що між першою `{` і останньою `}`. Тому вступи на зразок
   «Звичайно, ось пояснення…» на сторінку не потрапляють. Якщо JSON неправильний,
   показується помилка, а не сирий текст моделі.
4. Повзунок просто показує інше з п'яти пояснень, нових запитів не робить.

## Ключі

Свого сервера і свого ключа сервіс не має. Ключ вводиться в поле на сторінці, ніде не
зберігається і надсилається з браузера напряму в OpenRouter або Anthropic.

- **OpenRouter** — тільки безкоштовні моделі (назва закінчується на `:free`). Вони повільні
  й часто перевантажені.
- **Anthropic** — моделі Claude: Haiku 5.5, Sonnet 5.5, Opus 5.5, Fable 5.2. Запити платні.

Кнопка «Показати готовий приклад» показує збережену відповідь з `example.json`,
ключ для неї не потрібен.

## Файли

- `index.html`, `style.css` — сторінка й оформлення
- `levels.js` — промпт, запит до моделі, розбір відповіді
- `app.js` — форма, показ результату, повзунок
- `example.json` — збережений приклад
- `test.mjs` — перевірки для `levels.js`
- `deploy.py` — викладання на HuggingFace Spaces

## Запуск

```bash
python3 -m http.server 8000
```

Сторінка відкриється на http://localhost:8000. Перевірки: `node --test test.mjs`.

Спочатку я робив сервіс на Gradio, але безкоштовно розмістити Gradio на HuggingFace Spaces
не вдалося (потрібна підписка), тому переписав на звичайні HTML і JavaScript.
