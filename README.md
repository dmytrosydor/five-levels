# П'ять рівнів

Вебсервіс, який пояснює будь-яку тему на п'яти рівнях складності: для дитини, школяра,
студента, фахівця та експерта. Рівень перемикається повзунком.

Лабораторна робота № 8 з дисципліни «Обробка мови методами штучного інтелекту»
(LLM-проєкт, базовий рівень). Виконав Сидор Дмитро, група ШІ-42.

- Сервіс: https://huggingface.co/spaces/sydordmytro/five-levels
- Код: https://github.com/dmytrosydor/five-levels

## Як це працює

1. Користувач вводить тему, обирає, чий у нього ключ (OpenRouter чи Anthropic), вводить ключ
   і обирає модель.
2. Сторінка робить **один виклик LLM**. У системному промпті модель отримує опис п'яти
   рівнів і вимогу повернути лише JSON-об'єкт із ключами `child`, `school`, `student`, `pro`,
   `expert`.
3. Код дістає з відповіді JSON, перевіряє, що всі п'ять пояснень на місці, і будує результат.
4. Повзунок перемикає рівень без нових запитів: усі п'ять пояснень уже завантажені.

### Чому користувач бачить лише результат

Мовні моделі часто додають вступи на зразок «Звичайно, ось пояснення…». Тут це закрито
двома способами:

- промпт забороняє вступи, а запит вимагає JSON: в OpenRouter через
  `response_format: json_object`, в Anthropic через схему відповіді (`output_config.format`);
- з відповіді береться тільки те, що між першою `{` і останньою `}`, тож вступ, післямова
  чи markdown-обгортка на сторінку не потрапляють, навіть якщо модель їх додала.

Якщо у відповіді немає правильного JSON, користувач бачить повідомлення про помилку,
а не сирий текст моделі.

### Ключі й моделі

Сервіс не має власного сервера і власного ключа. Ключ вводиться в поле на сторінці й ніде
не зберігається: браузер надсилає його напряму тому сервісу, якому він належить. У коді
ключів немає.

Є два варіанти:

- **OpenRouter, безкоштовні моделі.** Ключ OpenRouter використовується лише для моделей, назва
  яких закінчується на `:free`, тому запити нічого не коштують. Платну модель код не пропустить:
  запит навіть не надсилається. У списку є Nemotron 3.5 Super, Gemma 4 31B, режим «Авто»
  (OpenRouter сам пробує три моделі по черзі, запит лишається один) і поле для іншої
  безкоштовної моделі. Безкоштовні моделі повільні (до хвилини) й бувають перевантажені.
- **Anthropic, моделі Claude.** Окреме поле для ключа Anthropic і вибір моделі: Claude Haiku 5.5,
  Sonnet 5.5, Opus 5.5 або Fable 5.2. Запити платні й ідуть напряму в Anthropic (Messages API).
  Haiku найдешевша (близько 0,1 цента за запит), Fable найсильніша й найдорожча.

Кнопка «Показати готовий приклад» показує збережену відповідь моделі з `example.json`.
Для неї не потрібен ключ і не виконується запит.

### Чому статична сторінка

Перша версія була на Python і Gradio. Безкоштовне розміщення Gradio на HuggingFace Spaces
тепер потребує підписки, тому сервіс переписано на звичайні HTML, CSS і JavaScript
і розміщено як статичний Space. Логіка лишилася та сама.

## Файли

| Файл | Що в ньому |
|---|---|
| `index.html` | Сторінка: опис сервісу, форма, місце для результату |
| `levels.js` | Промпт, запит до OpenRouter або Anthropic, розбір відповіді, підрахунок слів |
| `app.js` | Робота зі сторінкою: форма, показ результату, повзунок |
| `style.css` | Оформлення, світла й темна теми |
| `example.json` | Збережена відповідь моделі для кнопки з прикладом |
| `test.mjs` | Перевірки логіки з `levels.js` |
| `deploy.py` | Розміщення на HuggingFace Spaces |

## Локальний запуск

```bash
python3 -m http.server 8000
```

Після запуску сторінка доступна на http://localhost:8000.

Перевірки (потрібен Node.js 20 або новіший):

```bash
node --test test.mjs
```

## Технології

HTML, CSS, JavaScript без бібліотек; OpenRouter API (`chat/completions`) або Anthropic
Messages API (`/v1/messages`), на одне пояснення завжди один запит; HuggingFace Spaces (static).
