# П'ять рівнів

Вебсервіс, який пояснює будь-яку тему на п'яти рівнях складності: для дитини, школяра,
студента, фахівця та експерта. Рівень перемикається повзунком.

Лабораторна робота № 8 з дисципліни «Обробка мови методами штучного інтелекту»
(LLM-проєкт, базовий рівень). Виконав Сидор Дмитро, група ШІ-42.

## Як це працює

1. Користувач вводить тему і свій ключ OpenRouter.
2. Застосунок робить **один виклик LLM**. У системному промпті модель отримує опис п'яти
   рівнів і вимогу повернути лише JSON-об'єкт із ключами `child`, `school`, `student`, `pro`,
   `expert`.
3. Код дістає з відповіді JSON, перевіряє, що всі п'ять пояснень на місці, і будує сторінку.
4. Повзунок перемикає рівень у браузері. Нових запитів до моделі при цьому немає: усі п'ять
   пояснень уже завантажені.

### Чому користувач бачить лише результат

Мовні моделі часто додають вступи на зразок «Звичайно, ось пояснення…». Тут це закрито
двома способами:

- промпт забороняє вступи, а запит іде з `response_format: json_object`;
- з відповіді береться тільки те, що між першою `{` і останньою `}`, тож вступ, післямова
  чи markdown-обгортка на сторінку не потрапляють, навіть якщо модель їх додала.

Якщо у відповіді немає правильного JSON, користувач бачить повідомлення про помилку,
а не сирий текст моделі.

### Ключ і модель

- Ключ вводиться в поле на сторінці й ніде не зберігається: він лише передається
  в OpenRouter разом із запитом. У коді ключа немає.
- Типова модель — Claude Haiku 5.5: відповідь приходить приблизно за 8 секунд, один запит
  коштує близько 0,06 цента. У списку є ще GPT-6 Luna, а в поле можна вписати будь-яку
  модель з OpenRouter.
- Для ключа без коштів є пункт «Безкоштовні моделі». У запиті тоді передається список із
  трьох моделей: якщо перша перевантажена, OpenRouter сам бере наступну, а запит лишається
  один. Безкоштовні моделі часто перевантажені, тому типовою зроблено платну.
- Кнопка «Показати готовий приклад» показує збережену відповідь моделі з `example.json`.
  Для неї не потрібен ключ і не виконується запит.

## Файли

| Файл | Що в ньому |
|---|---|
| `app.py` | Запит до OpenRouter, розбір відповіді, побудова сторінки (Gradio) |
| `style.css` | Оформлення сторінки, світла й темна теми |
| `example.json` | Збережена відповідь моделі для кнопки з прикладом |
| `test_app.py` | Перевірки розбору відповіді та побудови HTML |

## Локальний запуск

```bash
pip install gradio==6.31.0 httpx
python app.py
```

Після запуску сторінка доступна на http://localhost:7860.

Перевірки:

```bash
pip install pytest
pytest test_app.py
```

## Технології

Python, Gradio 6, OpenRouter API (один запит `chat/completions`), HuggingFace Spaces.
